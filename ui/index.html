How sync, overlay, and IR work

Scrub or type HH:MM:SS.mmm, then Set sync on each camera. Use as ref on one camera so offsets can be calculated; it does not pick start or end, and it does not need to be selected as a feed. Turn align on, then set the shared start and end. Overlay is shown on previews immediately and burned into RTSP on Start (forces encode even at Original). IR publishes a second encoded path named camera_ir (thermal heatmap or green night vision). Original still 4K-copies the color feed and encodes IR at 720p. Create clip writes a synchronized start→end cut of every selected camera into the preset folder, with one subfolder per camera.
